L - IP blocks and where they came from
======================================

Every core, library, ROM and data file used by the project, with its origin and license.
Details, the notices the licenses ask for and what was changed: BUILDING_AND_LICENSES.md.
How much of each part is used: docs/L_Third_Party.docx.


1. Third-party FPGA cores
-------------------------

T80 (Z80 CPU)
    Used in:  LSpectrum; LMega (sound processor)
    Origin:   MiSTer ZX Spectrum core, commit af0e6723; Daniel Wallner, MikeJ, Sorgelig
    License:  BSD-style
    Changed:  no (T80/SOURCE.md)

T65 (6502 CPU)
    Used in:  L64 (6510 and the 1541 drive's processor), LTari, LNES
    Origin:   MiSTer Commodore 64 core, commit fe6dfe5; Daniel Wallner, Mike Johnson,
              Wolfgang Scherr, Morten Leikvoll, SzGy
    License:  BSD-style
    Changed:  no (T65/SOURCE.md)

fx68k (68000 CPU)
    Used in:  LMega
    Origin:   MiSTer Genesis core, commit adc0c42; Jorge Cwik
    License:  GPL-3
    Changed:  no (FX68K/SOURCE.md)

jt12 (YM2612) and jt89 (SN76489)
    Used in:  LMega (sound)
    Origin:   MiSTer Genesis core, commit adc0c42; Jose Tejada
    License:  GPL-3
    Changed:  no (JT12/SOURCE.md, JT89/SOURCE.md)

Mega Drive video processor (VDP)
    Used in:  LMega (video)
    Origin:   MiSTer Genesis core, commit adc0c42; Gregory Estrade, Till Harbaum,
              Alexey Melnikov, Gyorgy Szombathelyi
    License:  BSD-style
    Changed:  no (LMega/10cl025/rtl/genesis/SOURCE.md)

ZX Spectrum Next core (Z80N, ULA, Layer 2, sprites, tilemap, copper, DMA, sound, DivMMC ...)
    Used in:  LNext (the whole machine)
    Origin:   MiSTer ZXNext core, commit 7daebd1 (port by Alexey Melnikov) of the Spectrum
              Next core by Alvin Albrecht, Victor Trucco, Fabio Belavenuto
    License:  GPL-3
    Changed:  no (ZXNEXT/SOURCE.md). LNext builds two files from the unchanged ones with
              LNext/10cl025/tools/mk_c10_files.py (sprite attribute memories merged, the boot
              ROM split) and has its own memory file for the Cyclone 10 LP.

SD card made of logic (sd_card.sv)
    Used in:  LNext (the Next's card port; the real card is on the ESP32)
    Origin:   MiSTer framework, same commit; Till Harbaum, Sorgelig
    License:  LGPL-3
    Changed:  no (ZXNEXT/SOURCE.md)

JT49 (AY-3-8910 / 8912)
    Used in:  LSpectrum (sound)
    Origin:   Jose Tejada, version 1.0
    License:  GPL-3 or later
    Changed:  no (LSpectrum/ep4_ce15/rtl/jt49/)

VIC-II Kawari
    Used in:  L64 (video)
    Origin:   github.com/randyrossi/vicii-kawari, commit 95ed201; Randy Rossi
    License:  GPL-3
    Changed:  small changes, marked "// L64:" (L64/ep4_ce15/rtl/vicii/)

SID 6581 / 8580
    Used in:  L64 (sound)
    Origin:   MiSTer Commodore 64 core, commit fe6dfe5; converter and filter from
              Dag Lem's reDIP-SID (Alexey Melnikov)
    License:  CERN-OHL-S v2 (sid_dac.sv, sid_filter.sv); GPL-2 or later (the rest)
    Changed:  no (L64/ep4_ce15/rtl/sid/)

CIA 6526
    Used in:  L64 (two)
    Origin:   MiSTer Commodore 64 core, commit fe6dfe5
    License:  GPL-2 or later
    Changed:  small changes, marked "// L64:" (L64/ep4_ce15/rtl/cia/)

VIA 6522
    Used in:  L64 (the 1541 drive)
    Origin:   MiSTer Commodore 64 core, commit fe6dfe5; Gideon Zweijtzer
    License:  GPL-3
    Changed:  no (L64/ep4_ce15/rtl/via/)


2. Vendor IP, generated by Quartus
----------------------------------

altpll, altclkctrl, altddio_out, altremote_update, the flash access block
(cycloneive_asmiblock / cyclone_asmiblock) and the inferred altsyncram block RAMs.
Generated from parameters; no Intel source is in the repository.
License: the Intel FPGA software license that comes with Quartus Prime Lite.


3. Written for this project (MIT license)
-----------------------------------------

SDRAM controller      sdram_ram.v (and LMega's copy md_sdram.v): RAM on the W9825G6KH at up to
                      112 MHz
Machine menu          AMenu: menu, remote update into a machine, installation from the SD card
Shared parts          flash ROM loader, ESP32 link and register bus, on-screen display,
                      Bluetooth audio (I2S), sigma-delta audio, video clock switch, VGA timing
LSpectrum             bus, paging, video, contention, floating bus, keyboard, snapshots
                      (around T80 and JT49)
L64                   bus and PLA, 6510 port, frame buffer, turbo, snapshots, the 1541's drive
                      logic and GCR (around the cores of section 1)
LTari                 ANTIC, GTIA, POKEY and PIA, written from the Altirra Hardware Reference
                      Manual; only the CPU is external
LNES                  picture processor, sound, cartridge mappers, bus and frame buffer, written
                      from the NESdev documentation; only the CPU is external
LMega                 system logic, memory, line doubler and frame buffer (around the cores of
                      section 1)
LNext                 memories for the Cyclone 10 LP, SD card link to the ESP32, keyboard, line
                      doubler, top level (around the Spectrum Next core). Its SDRAM controller
                      next_sdram.v follows the MiSTer port's (Alexey Melnikov, GPL-2 or later)
                      and carries that notice.
ESP32 firmware        SD card browser, FAT, tape player and recorder, snapshots, disk and
                      cartridge loaders, installers, menus
I/O boards            Extra_PCB_CycloneIV (revision 1), Extra_PCB_CycloneIV_R2 (revision 2)
